# Finora — Personal Finance & Budget Analytics Dashboard

**Finora** is a modern, responsive personal finance dashboard designed to help users manage transactions, monitor expenses, track budgets, and understand their spending habits through interactive data visualizations.

The application provides a centralized interface for recording financial transactions, categorizing expenses, analyzing monthly spending, and tracking budget limits.

## ✨ Features

- **Dashboard Overview:** View key financial summaries, including income, expenses, and balance.
- **Transaction Management:** Add, view, edit, and delete income and expense records.
- **Interactive Charts:** Visualize spending patterns and monthly expenses using Chart.js.
- **Category-Based Filtering:** Filter transactions by category, type, or date.
- **Budget Tracking:** Set budget limits and monitor spending against allocated amounts.
- **Persistent Storage:** Store transaction and budget data using browser local storage.
- **Responsive Design:** Access the dashboard across desktop, tablet, and mobile devices.
- **Dynamic Updates:** Automatically refresh financial summaries and charts when transactions change.

## 🛠️ Tech Stack

- **React.js** — Component-based user interface development
- **JavaScript (ES6+)** — Application logic and interactive functionality
- **CSS3** — Responsive layouts and visual styling
- **Chart.js** — Financial data visualization
- **Browser Local Storage** — Client-side data persistence
- **Git & GitHub** — Version control and project hosting

## 📊 Dashboard Modules

### 1. Financial Overview
Display total income, total expenses, available balance, and budget utilization.

### 2. Transaction Management
Record financial transactions with descriptions, amounts, dates, categories, and transaction types.

### 3. Expense Analytics
Analyze category-wise expenses and monthly spending trends through interactive charts.

### 4. Budget Management
Create spending limits for selected categories and monitor progress toward those limits.

### 5. Transaction Filters
Quickly find records using category, transaction type, and date-based filters.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed
- Git installed
- A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd finora
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

*Note: These commands assume a Vite-based React project. Adjust them if your project uses a different setup.*

## 💾 Data Storage

Finora uses browser local storage to retain supported transaction and budget data across page reloads. Since the application is frontend-based, the stored data remains in the user's browser rather than a centralized database.
